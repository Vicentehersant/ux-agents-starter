---
description: Accessibility pass (WCAG 2.2 AA) on a page or component, with fixes
argument-hint: <file, route or component>
---

Run an accessibility pass on: $ARGUMENTS

1. Use **a11y-auditor** to audit (contrast, semantics, keyboard, forms, ARIA, motion, target size).
2. Present the findings table and ask before applying fixes that change visual design.
3. Apply safe fixes (labels, alt text, semantics, focus styles) and re-verify.
4. Report: fixed, pending (needs a design decision), pass/fail.
